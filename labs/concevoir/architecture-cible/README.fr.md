# Décider d'une architecture cloud cible

Comparez des options complètes au lieu de choisir un produit à partir d'une
liste de fonctionnalités.

| | |
|---|---|
| Cible | votre poste, répertoire `challenge/work/`, sans compte cloud |
| Durée | environ 40 minutes |
| Page associée | [la leçon du site](https://www.stephane-robert.info/docs/cloud/capstone/decider-une-architecture-cible/) |

```bash
dsoxlab run   concevoir-architecture-cible
dsoxlab check concevoir-architecture-cible
```

## Ce que vous saurez faire

- Comparer deux options selon le coût, l'exploitation, la résidence, la
  disponibilité, la portabilité et les performances.
- Consigner une décision, ses raisons et un risque accepté dans un ADR structuré.

## Limite de la preuve

Les chiffres sont des données d'exercice contrôlées, pas des tarifs fournisseur
ni la preuve qu'un service cloud réel a été provisionné.
