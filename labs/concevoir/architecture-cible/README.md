# Decide on a target cloud architecture

Compare complete options rather than choosing a product from a feature list.

## What you will be able to do

- Compare two architecture options on cost, operations, residency,
  availability, portability and performance.
- Record a decision, rationale and accepted risk in a structured ADR.

## Evidence boundary

The figures are controlled exercise facts, not provider prices or an assertion
that a real cloud service has been provisioned.
