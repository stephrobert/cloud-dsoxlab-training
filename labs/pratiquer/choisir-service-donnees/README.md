# Choose a data service

This lab turns a workload brief into a data-service decision. Compare the
available exercise options, account for the team's operational capacity, and
record private connectivity, replication, failover and restore verification.

| | |
|---|---|
| Target | your machine, `challenge/work/` directory, no cloud account |
| Duration | about 35 minutes |
| Companion lesson | [the lesson on the site, in French](https://www.stephane-robert.info/docs/cloud/donnees/) |

```bash
dsoxlab run   choisir-service-donnees
dsoxlab check choisir-service-donnees
```

All service capabilities and costs in the fixture are synthetic exercise data,
not claims about a cloud provider. The lab grades the decision artifact; it
does not provision a database or prove a live recovery.
