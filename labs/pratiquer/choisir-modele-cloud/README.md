# Choose a cloud service and deployment model

This lab practises the distinction between what a cloud service provides and
where that service is deployed.

| | |
|---|---|
| Target | your machine, `challenge/work/` directory, no cloud account |
| Duration | about 30 minutes |
| Companion lesson | [the lesson on the site, in French](https://www.stephane-robert.info/docs/cloud/fondamentaux/modeles-cloud-iaas-paas-saas/) |

```bash
dsoxlab run   pratiquer-choisir-modele-cloud
dsoxlab check pratiquer-choisir-modele-cloud
```

## What you will be able to do

- Choose a service model and a deployment model from workload constraints.
- Describe the provider/team security responsibility boundary.

## Evidence boundary

This is a structured decision exercise. It does not provision a provider
service or prove a provider's actual security controls.

See the lesson:
<https://www.stephane-robert.info/docs/cloud/fondamentaux/modeles-cloud-iaas-paas-saas/>.
