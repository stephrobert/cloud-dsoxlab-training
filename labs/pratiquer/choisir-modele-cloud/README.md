# Choose a cloud service and deployment model

This lab practises the distinction between what a cloud service provides and
where that service is deployed.

## What you will be able to do

- Choose a service model and a deployment model from workload constraints.
- Describe the provider/team security responsibility boundary.

## Evidence boundary

This is a structured decision exercise. It does not provision a provider
service or prove a provider's actual security controls.
